# @workspace/config

Reusable TypeScript and build configurations:

- `@workspace/config/tsconfig/base.json` — strict shared defaults.
- `@workspace/config/tsconfig/library.json` — library/declaration settings.
- `@workspace/config/tsconfig/app.json` — browser app settings.
- `@workspace/config/bunup` — shared Bunup preset for ESM/Node builds with declarations, clean output, and sourcemaps.
