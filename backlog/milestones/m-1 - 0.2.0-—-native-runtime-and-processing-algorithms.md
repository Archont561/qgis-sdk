## Version policy

0.2.0 is a SemVer planning target, not a published version. Experimental 0.x breaking changes require a documented minor release; patches are compatible fixes. Prereleases may use 0.2.0-alpha.1 or 0.2.0-beta.1. Do not bump manifests during planning. When the milestone closes, the minor is set **explicitly** (`release.py plan --bump minor`); feature and fix work inside the milestone only bumps the patch, so automatic derivation proposes the patch and the milestone release is a deliberate act. `qgis-sdk` and `qgis-sdk-bridge` are stamped together at one shared version ([decision-24](../decisions/decision-24%20-%20Release-the-Python-SDK-and-TypeScript-bridge-at-one-shared-version.md)); IPC protocol versions stay independent of it. Stable 1.0.0 requires a later explicit API-stability decision.
