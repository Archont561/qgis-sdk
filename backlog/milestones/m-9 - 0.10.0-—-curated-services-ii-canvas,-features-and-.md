## Description and exit criteria

[decision-54](../decisions/decision-54%20-%20Cover-every-QGIS-service-and-layer-kind-through-the-contract-fake-native-host-grant-pattern-under-one-grant-vocabulary.md) answers "what is not mapped": the curated surface is vector-only
and workflow-shaped, and everything else means `ctx.desktop.iface`. This
milestone is the first of two coverage batches, each service landing with
all six parts (Protocol, models, fake, native adapter, host operations,
grants) under one grant vocabulary shared by page, console and agent
([TASK-84](../tasks/task-84%20-%20Unify-the-grant-vocabulary-across-web-agent-and-console-and-publish-the-service-coverage-map.md)), with the service coverage map
([doc-22](../docs/plans/doc-22%20-%20Service-coverage-map.md)) as the source of truth.

Exit criteria, both required:

- **`qgis-sdk`** — released at 0.10.0 from one green gate ([TASK-90](../tasks/task-90%20-%20Prepare-and-qualify-0.10.0-release.md)):
  `canvas` ([TASK-85](../tasks/task-85%20-%20Add-the-canvas-service-extent-scale-CRS-zoom-refresh-map-themes-extent-stream-and-capture-tools.md)), `features` and `expressions` ([TASK-86](../tasks/task-86%20-%20Add-the-features-and-expressions-services-paged-iteration-filters-geometry-models-attribute-read-editing-sessions-evaluate-and-validate.md)),
  rasters with the kinded `LayerInfo` ([TASK-87](../tasks/task-87%20-%20Add-rasters-open-band-and-statistics-info-sample-at-point-export.md)), the extended `project`
  with the layer tree ([TASK-88](../tasks/task-88%20-%20Extend-the-project-service-CRS-read-write-and-save-variables-custom-properties-bookmarks-and-the-layer-tree.md)), `layouts` and atlas ([TASK-89](../tasks/task-89%20-%20Add-layouts-and-atlas-list-template-load-export-to-PDF-PNG-and-SVG-as-jobs-atlas-iteration-with-progress.md));
  doc-22 shows each complete; doc-12's 0.10.0 notes.
- **`@archont561/qgis-sdk`** — **next minor** from the same gate: the host
  manifest regenerated with every new operation, `HOST_FINGERPRINT` moved,
  `generated/host.ts` and the typed `qgis.host` regenerated (never
  hand-edited), `HOST_SCHEMA_VERSION` and `BRIDGE_PROTOCOL_VERSION`
  unchanged, shown by `release.py verify-versions`.

## Version policy

0.10.0 is a SemVer planning target, not a published version, until its gate is
authorised. Experimental 0.x breaking changes require a documented minor
release; patches are compatible fixes. Prereleases may use `0.10.0-rc.N` for a
pipeline rehearsal (dry run, no uploads). Do not bump manifests during
planning. `qgis-sdk`, `@archont561/qgis-sdk` and `@archont561/qgis-sdk-ui`
carry **independent** versions, each derived from its own commits and stamped
by its own release tag ([decision-25](../decisions/decision-25%20-%20Version-each-package-independently-behind-a-shared-contract-version.md)); the bridge minor is paired by the shared plugin-description contract version and the regenerated host manifest. Stable 1.0.0 requires a later
explicit API-stability decision.
