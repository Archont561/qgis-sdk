## Description and exit criteria

Generated typed clients, per-view authorization, bounded IPC lifecycle and native WebEngine integration; vanilla and React use one runtime.

## Version policy

0.3.0 is a SemVer planning target, not a published version. Experimental 0.x breaking changes require a documented minor release; patches are compatible fixes. Prereleases may use 0.3.0-alpha.1 or 0.3.0-beta.1. Do not bump manifests during planning. Package versions and IPC protocol versions are independent. Stable 1.0.0 requires a later explicit API-stability decision.
