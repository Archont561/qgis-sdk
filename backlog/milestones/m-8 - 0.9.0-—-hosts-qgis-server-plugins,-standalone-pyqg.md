## Description and exit criteria

Re-pointed on 2026-10-26: `m-8` held the deferred native-compute
reservation at 0.9.0; that research is post-1.0 by its own title and moves
to 1.1.0 as [m-11](m-11%20-%201.1.0-%E2%80%94-deferred-native-compute-feasibility-(tenta.md). The number goes to the first of three
coverage releases the owner asked for. [decision-52](../decisions/decision-52%20-%20Run-one-plugin-class-on-three-hosts-QGIS-Desktop-QGIS-Server-and-standalone-PyQGIS-apps.md): one author class runs on
three hosts - QGIS Desktop, QGIS Server (`@server.filter`, `@server.service`,
`@server.access_control`, generated `serverClassFactory`, in-process
`QgsServer` tests) and standalone PyQGIS apps (`qgis_sdk.app.run`, an
optional canvas window, `qgis-sdk run`, `build --target app`) - with
`[tool.qgis-sdk] hosts` declaring which, and capabilities refusing by name
elsewhere. [decision-53](../decisions/decision-53%20-%20Run-offloaded-job-steps-as-QgsTasks-under-QgsTaskManager-and-keep-the-step-scheduler-on-the-driving-thread.md): offloaded job steps run as `QgsTask`s under
`QgsTaskManager`, each job visible as a parent task with progress and
cancel, the step scheduler and ownership rules unchanged.

Exit criteria, both required:

- **`qgis-sdk`** — `qgis-sdk-runtime`, `qgis-sdk-tools` and the `qgis-sdk`
  kit are released at 0.9.0 from one green gate ([TASK-83](../tasks/task-83%20-%20Prepare-and-qualify-0.9.0-release.md)): the server
  host ([TASK-80](../tasks/task-80%20-%20Add-the-QGIS-Server-host-server-declarations-ServerContext-generated-serverClassFactory-in-process-QgsServer-tests-and-dev-host-server.md)), the app host ([TASK-81](../tasks/task-81%20-%20Add-the-standalone-app-host-qgis_sdk.app.run-an-optional-canvas-window-qgis-sdk-run-and-build-target-app.md)), the task-manager workers
  ([TASK-82](../tasks/task-82%20-%20Run-offloaded-job-steps-as-QgsTasks-under-QgsTaskManager-with-the-job-visible-as-a-parent-task.md)); the reference example with server and app variants; the
  scaffold with `--host`; doc-12's 0.9.0 notes.
- **`@archont561/qgis-sdk`** — **no release expected**: hosts and
  scheduling change nothing on the wire. The gate shows this (no file under
  `packages/qgis-sdk-typescript` changed, no npm version consumed) rather
  than assuming it.

## Version policy

0.9.0 is a SemVer planning target, not a published version, until its gate is
authorised. Experimental 0.x breaking changes require a documented minor
release; patches are compatible fixes. Prereleases may use `0.9.0-rc.N` for a
pipeline rehearsal (dry run, no uploads). Do not bump manifests during
planning. `qgis-sdk`, `@archont561/qgis-sdk` and `@archont561/qgis-sdk-ui`
carry **independent** versions, each derived from its own commits and stamped
by its own release tag ([decision-25](../decisions/decision-25%20-%20Version-each-package-independently-behind-a-shared-contract-version.md)); the two npm packages are expected not to move in this milestone. Stable 1.0.0 requires a later
explicit API-stability decision.
