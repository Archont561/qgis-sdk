## Description and exit criteria

Re-pointed from 0.6.0 to 0.7.0 on 2026-10-25: the 0.6.0 number went to the
API-ergonomics release ([m-6](m-6%20-%200.6.0-%E2%80%94-API-ergonomics-function-jobs-and-capability-attributes.md))
because two breaking runtime changes had landed on `main` and a deferred
research reservation must not share a number with a release that ships.

Optional future research only after a fresh go/no-go decision; no commitment to
Rust shipping or stable 1.0.0. Nothing here is scheduled, and nothing here is a
reason to hold a release.

Exit criteria, both required **if, and only if, the research is revived**:

- **`qgis-sdk`** — a prototype backend is evaluated against the qualified
  reference workflow and the outcome, including a no-go, is recorded.
- **`@archont561/qgis-sdk`** — the revival states its bridge impact
  explicitly: either "none, wire contract unchanged" or the contract version
  bump the prototype forces. A revival that cannot answer this does not start.

## Bridge track

| Change to `packages/qgis-sdk-typescript` | Task | Resulting bridge version |
| --- | --- | --- |
| None expected: a native backend changes what runs behind Python, not what crosses `QWebChannel`. Re-checked against the prototype's result schema if the research is revived. | — | no release |

Deferred milestones still carry the pairing rule, because an unexamined
"probably nothing" is how a wire contract drifts:

- The bridge is a transport and contract package. A native compute backend
  changes what runs behind Python, not what crosses `QWebChannel`, so the
  expected bridge delta is **zero** — and that expectation has to be re-checked
  against the prototype's result schema rather than assumed.
- If the research is revived, the revived scope restates the bridge delta and
  the contract version it would need. A prototyped result shape that leaks a
  native handle would be a bridge contract change, not an implementation
  detail, and would be refused under
  [decision-9](../decisions/decision-9%20-%20Declare-allowlisted-typed-bridge-endpoints-with-runtime-owned-routers.md).
- No 0.7.0 artifact is stamped or published while the milestone stays
  tentative. The independent-version rule
  ([decision-25](../decisions/decision-25%20-%20Version-each-package-independently-behind-a-shared-contract-version.md))
  applies when a release happens, and there is no release here.

## Version policy

0.7.0 is a SemVer planning target, not a published version, and the reservation
itself is tentative deferred research — it requires renewed approval, not a
Rust-shipping commitment. Experimental 0.x breaking changes require a documented
minor release; patches are compatible fixes. Prereleases may use 0.7.0-alpha.1
or 0.7.0-beta.1. Do not bump manifests during planning. `qgis-sdk` and `@archont561/qgis-sdk` carry **independent** versions, each derived
from its own commits and stamped by its own release tag ([decision-25](../decisions/decision-25%20-%20Version-each-package-independently-behind-a-shared-contract-version.md));
nothing is released while this milestone stays tentative. A shared
plugin-description contract version is what pairs them. Stable 1.0.0 requires a later
explicit API-stability decision.
