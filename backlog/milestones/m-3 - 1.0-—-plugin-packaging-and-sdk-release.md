## Description

Ship developer tooling and a reproducible build that creates a QGIS-installable plugin ZIP. The proposed policy is to bundle only needed runtime modules in each plugin archive and not require a separate `qgis-sdk-runtime` installation for v1.

## Exit criteria

- A clean build creates a ZIP with the plugin package at the expected root and required metadata/assets.
- Dev dependencies, tests, caches, and development web-server assets are excluded.
- The archive can be installed/loaded in a clean supported QGIS profile/runtime.
- SDK/tooling version and plugin artifact versioning are clear and repeatable.
- Supported QGIS/Python/platform claims and release checks are documented.
