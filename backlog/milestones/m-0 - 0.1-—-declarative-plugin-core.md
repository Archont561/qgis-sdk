## Description

Establish the minimum useful plugin project and the Python-first authoring/runtime contract: scaffold, metadata, lifecycle integration, inspectable declarations, and a generated plugin description. This milestone does not imply a second JSON authoring system or a Rust runtime.

## Exit criteria

- A new project scaffold has a valid QGIS plugin structure and an understandable Python entry point.
- Plugin declarations are introspectable and produce a deterministic, validated description.
- A minimal plugin can be loaded and unloaded through QGIS's plugin lifecycle.
- Pure-Python tests cover declaration and description behavior without requiring QGIS.
