## Description and exit criteria

QGIS-free contracts and deterministic declarations; validator and scheduler spikes record evidence and blockers.

## Version policy

0.1.0 is a SemVer planning target, not a published version. Experimental 0.x breaking changes require a documented minor release; patches are compatible fixes. Prereleases may use 0.1.0-alpha.1 or 0.1.0-beta.1. Do not bump manifests during planning. Package versions and IPC protocol versions are independent. Stable 1.0.0 requires a later explicit API-stability decision.
