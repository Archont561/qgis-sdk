## Description

Provide a usable local feedback loop for real QGIS Desktop plugins and a clearly distinct standalone PyQt/PyQGIS mode, plus layered pytest support. WebEngine plugins may use a local frontend dev server/HMR; Python changes reload the plugin/view where safe and otherwise provide an explicit restart fallback.

## Exit criteria

- QGIS Desktop can load the source plugin through a documented dev command/configuration.
- Desktop-dependent features are tested in Desktop, not represented as equivalent by standalone PyQt.
- Pure, Qt, QGIS-runtime, and bridge tests can be selected independently.
- Web assets use HMR in development and production assets in the build.
- Reload behavior and fallback are observable and documented; remote debugging is opt-in.
