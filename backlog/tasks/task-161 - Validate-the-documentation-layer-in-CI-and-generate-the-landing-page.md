## Description

Make docs/ the entry point to the documentation: it states how documentation is written here and where each kind of knowledge lives, and every claim it makes is checked. Four layers gate a pull request - alint for repository conventions, markdownlint-cli2 for Markdown structure, Vale for writing style and lychee for links - with the prose checks in .github/workflows/docs-check.yml.
