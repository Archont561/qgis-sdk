## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Step 1 of decision-35. Move the developer tooling - __main__, cli, scaffold, check, devtools, pytest_plugin, the bridge generator and FakeCliRuntime - from src/qgis_sdk to src/qgis_sdk_tools, keep both trees in the one qgis-sdk wheel, and make the boundary a tested rule: the runtime tree imports only the stdlib and never tools; tools imports the runtime. Environment variable names a generated plugin reads become runtime constants. The CLI command names, the generated project layout and the runtime API are unchanged; the console script entry point, the scaffold's pytest addopts and the Python import paths of scaffold/check move, with a migration note in doc-12. No new distribution, no version bump.
<!-- SECTION:DESCRIPTION:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Delivered in PR #73 (decision-35 step 1). src/qgis_sdk_tools holds __main__, cli, scaffold, check, devtools, pytest_plugin, generate (the bridge generator) and testing (FakeCliRuntime); the console script is qgis_sdk_tools.__main__:main and python -m qgis_sdk is retired in favour of python -m qgis_sdk_tools; every CLI command (new, check, bridge generate, test, dev) is exercised by the moved test modules and the opt-in harnesses (AC #1). tests/test_pure_imports.py has a runtime-only layer table and two boundary tests: the runtime tree never imports qgis_sdk_tools, and the tools tree imports only the runtime, the stdlib, Typer/Click, pytest and the qgis host (AC #2). qgis_sdk.environment defines QGIS_SDK_DEV_SERVER and QGIS_SDK_TEST_TARGET once; devtools, the pytest plugin and the generated webview import them, and the scaffold writes addopts = -p qgis_sdk_tools.pytest_plugin; generated projects pass check and test in the unit suite and against QGIS 4.2.3 (AC #3). doc-12 carries the migration note and the moved paths, doc-14 the two-tree wheel; harnesses on the moved tooling: devtools 9/9, scaffold web 8/8 (Bun), scaffold desktop 10/10 (AC #4). The wheel still ships both trees; the distribution split is TASK-57.
