## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Step 1 of decision-35. Move the developer tooling - __main__, cli, scaffold, check, devtools, pytest_plugin, the bridge generator and FakeCliRuntime - from src/qgis_sdk to src/qgis_sdk_tools, keep both trees in the one qgis-sdk wheel, and make the boundary a tested rule: the runtime tree imports only the stdlib and never tools; tools imports the runtime. Environment variable names a generated plugin reads become runtime constants. The CLI command names, the generated project layout and the runtime API are unchanged; the console script entry point, the scaffold's pytest addopts and the Python import paths of scaffold/check move, with a migration note in doc-12. No new distribution, no version bump.
