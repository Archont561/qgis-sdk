## How do I install the Python kit?

<Tabs items={["pip", "pixi", "from source"]} defaultValue="pip">
<Tab value="pip">
From PyPI, into any environment - a virtualenv, Pixi, the system interpreter:

```sh
pip install qgis-sdk
```

</Tab>
<Tab value="pixi">
From the prefix.dev channel:

```sh
pixi add --channel https://prefix.dev/archont561/archont561 qgis-sdk
```

</Tab>
<Tab value="from source">
In a clone of this repository, which is what the contributing guides assume:

```sh
pixi install
pixi run -e default python -m qgis_sdk_tools --help
```

</Tab>
</Tabs>

`qgis-sdk` installs the command and pins `qgis-sdk-runtime` - what a plugin
imports inside QGIS - at its own version. The runtime alone, for a QGIS Python
console or a copy to vendor, is `pip install qgis-sdk-runtime`. Nothing is
written into a QGIS install: a built plugin carries its own copy.

## Which Python?

Any Python 3.11+ runs the tools, and a virtualenv is the normal place to work -
[the Python guide](/python/installation/#if-you-arrived-from-pyqgis-do-not-use-a-virtualenv)
explains why the "use QGIS's interpreter" advice is for scripts, and names the
three places the coupling is real.

## How do I install the TypeScript SDK?

Only a plugin with a web page needs it; `qgis-sdk new --web` writes the
dependency for you.

<Tabs items={["bun", "npm"]} defaultValue="bun">
<Tab value="bun">
```sh
bun add @archont561/qgis-sdk        # or its unscoped alias: bun add qgis-sdk
bun add @archont561/qgis-sdk-ui     # the web components, optional
```

</Tab>
<Tab value="npm">
```sh
npm install @archont561/qgis-sdk     # or: npm install qgis-sdk
npm install @archont561/qgis-sdk-ui  # the web components, optional
```

</Tab>
</Tabs>

## Did it work?

```sh
qgis-sdk --help
qgis-sdk targets      # the support matrix, and where this host stands in it
```
